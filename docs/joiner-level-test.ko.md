# 합류자 레벨 테스트 (약 30분)

목적: 점수를 매겨 탈락시키는 게 아니라, 어느 역할이 잘 맞는지 찾는 것입니다. 코딩 지식은 필요 없습니다. 검색과 AI 사용은 자유입니다. 대신 **어떻게 했는지 말로 설명**하게 하세요.

## 1. 소통 (DM 답장) — 10분
상황: 레딧 사용자가 "Atlas는 자꾸 CAPTCHA에 걸려서 포기했어요"라고 글을 남겼습니다.
과제: 이 사람에게 보낼 첫 DM을 3~4문장으로 쓰세요. 조건은 두 가지입니다. 광고처럼 보이면 안 되고, "어떤 작업이 실패했는지"를 물어야 합니다.

## 2. 관찰 (써 보고 찾기) — 10분
과제: 아무 사이트(쇼핑몰, 뉴스 등)에서 AI 기능이 있는 브라우저나 챗봇에 "가장 싼 OO 찾아줘"를 시키세요. 잘못된 점이나 이상한 점을 3개 이상 찾아 적으세요.

## 3. 설명 (버그 리포트) — 5분
과제: 2번에서 찾은 문제 하나를 `docs/tester-guide.ko.md`의 양식으로 쓰세요. 개발자가 읽고 그대로 재현할 수 있어야 합니다.

## 4. AI 다루기 — 5분
과제: AI에게 "Halo를 소개하는 베타 신청 글"을 쓰게 하세요. 결과가 별로면 한 번 고쳐 달라고 해서 더 낫게 만드세요. 무엇을 고쳤는지 한 줄로 말하세요.

## 채점 (항목당 0~3점)
| 항목 | 0 | 1 | 2 | 3 |
|------|---|---|---|---|
| 소통 | 광고 같음 | 어색하지만 질문은 함 | 자연스럽고 질문 있음 | 상대 글을 인용하고 부담 없이 답하게 만듦 |
| 관찰 | 0~1개 | 2개 | 3개, 구체적 | 3개 이상 + 심각도 구분 |
| 설명 | 재현 불가 | 일부만 재현 | 재현 가능 | 재현 가능 + 비교 결과까지 |
| AI 다루기 | 그대로 복붙 | 한 번 고침 | 이유를 알고 고침 | 조건을 주고 반복 개선 |

## 결과로 보는 역할
- **소통이 높음** → 사용자 대화(DM 답장, 피드백 수집) 담당.
- **관찰 + 설명이 높음** → 테스터, 경쟁 제품 비교 담당.
- **AI 다루기가 높음** → 문구, 베타 글, 문서 담당. 나중에 간단한 설정 작업도 가능.
- **전부 낮음** → 한 가지만 맡기세요(예: 하루에 DM 2개 답장). 실력은 늘어납니다.

## 주의
- 이 점수는 현재 시점의 참고용입니다.
- 서로 비교하거나 평가하는 용도로 쓰지 마세요.
