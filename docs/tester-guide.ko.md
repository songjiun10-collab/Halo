# Halo 테스터 가이드

코드를 몰라도 됩니다. 평범한 작업을 시켜 보고, 막히면 아래 양식으로 적어 주세요.

## 0. 시작 전 (개발자가 한 번 해 주는 일)
1. 개발자가 `npm --prefix apps/computer-browser start`로 Halo를 띄웁니다. (README의 "Run locally" 참고)
2. 개발자가 AI 제공자(planner)를 설정합니다. 설정법: `apps/computer-browser/main/harness/providers/README.ko.md`
3. **테스트용 계정만 쓰세요.** 실제 카드, 실제 은행, 개인 계정으로 로그인하지 않습니다.
4. 결제 기능은 꺼진 상태로 시작합니다. 결제가 필요한 작업은 "결제 직전까지만" 시키세요.

## 1. 테스트 작업 5개
각 작업을 Halo에 말로 시키고, 끝까지 가는지 봅니다. 가능하면 같은 작업을 다른 브라우저(Atlas, Dia, Aside, Arc)에도 시켜서 비교해 주세요.

| # | 시킬 말 | 보는 것 |
|---|---------|---------|
| 1 | "OO 노트북 가격을 두 사이트에서 비교해서 알려줘" | 두 곳을 다 봤는지, 가격이 맞는지 |
| 2 | "OO 기사 요약해줘" | 페이지를 제대로 읽었는지 |
| 3 | "내일 서울 날씨 찾아줘" | 단순한 검색이 끝까지 가는지 |
| 4 | "항공권 최저가 찾아줘 (결제는 하지 마)" | 폼 입력, 결제 직전에 멈추는지 |
| 5 | "OO 사이트 로그인 필요한 페이지 열어줘" | 로그인이 필요할 때 멈추고 물어보는지 |

## 2. 이런 건 꼭 적어 주세요
- CAPTCHA가 나와서 멈췄다 (Halo는 풀지 않고 다른 출처로 돌아가거나 사용자에게 넘깁니다)
- 승인 창이 떴는데 이유를 알 수 없었다
- 같은 행동을 반복했다
- 램을 많이 쓰거나 느렸다
- 하지 않은 일을 했다고 말했다 (이건 제일 중요합니다)

## 3. 실패 리포트 양식 (복사해서 쓰세요)

```
시킨 말(그대로):
사이트:
어디서 멈추거나 틀렸나:
화면 캡처: (있으면 파일 이름)
다른 브라우저에서는: (같은 작업, 결과)
심각도: 작업이 아예 실패 / 결과가 틀림 / 불편함
```

리포트는 `docs/tester-reports/날짜-이름.md`로 저장하거나 개발자에게 그대로 보내면 됩니다.

## 4. 개발자에게
- 리포트를 받으면 같은 말로 재현해 보고, 재현되면 고칩니다.
- 합류자가 쓰는 빌드는 하나로 정해 두세요.
- 결제 코드(`payment-mandate.js`, `task-controller.js`의 결제 부분)는 리뷰 없이 바꾸지 않습니다.
