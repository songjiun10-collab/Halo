# 동업자 브리핑 (한 쪽)

코드를 몰라도 읽고 바로 시작할 수 있게 썼습니다. 모르는 말은 맨 아래 용어 설명을 보세요.

## 1. Halo가 뭔가요
Halo는 **AI가 대신 웹사이트를 돌아다니며 일을 해 주는 브라우저**입니다. 크롬처럼 탭이 있고, 거기에 "이거 찾아줘", "이거 비교해줘"라고 말로 시키면 에이전트가 사이트를 열고 클릭하고 정리해 줍니다. 사람이 막히면(로그인, 결제, CAPTCHA) 멈추고 물어봅니다.

차별점으로 삼는 것: 위험한 행동(결제, 개인정보 입력)은 AI가 알아서 하지 못하게 **코드가 막습니다**. AI의 판단에 맡기지 않습니다.

## 2. Halo가 할 수 있는 것 (기능 목록과 체크표)

코드와 화면 정의를 읽어 정리한 목록입니다. **실제로 다 되는지는 확인하지 못했습니다.** 직접 써 보며 맨 오른쪽 칸에 O(됨) / X(안 됨) / ?(모르겠음)를 적어 주세요. X와 ?가 베타 전에 고칠 목록이 됩니다.

### 브라우저 기본
| 기능 | 설명 | 확인 |
|---|---|---|
| 탭 | 새 탭, 닫기, 전환, 모든 탭 보기 화면 | |
| 주소창 | 주소나 검색어 입력. **Tab/Ask** 스위치에서 Ask로 바꾸면 입력한 글이 에이전트 작업이 됨 | |
| 뒤로/앞으로, 새 창, 공유 | 공유는 현재 페이지 링크를 복사 | |
| 북마크 | 사이드바에서 사이트 바로가기 최대 8개 | |
| **세로 탭 모드** (새로 추가) | 사이드바 Tabs 제목 옆 ⇅ 버튼. 켜면 위의 탭 줄이 사라지고 탭이 사이드바로 | |
| **탭 그룹** (새로 추가) | 탭 행의 ▤ 아이콘으로 그룹 만들기·추가·해제, 그룹 접기, 이름 바꾸기(더블클릭), 한 번에 전체 해제 | |
| 단축키 | `Shift+/`로 전체 목록. 예: 새 탭 ⌘T, 주소창 ⌘L, 새 작업 ⌘K, 설정 ⌘, | |
| 크롬에서 로그인 가져오기 | 크롬의 로그인 정보를 허용한 사이트만 가져오는 기능이 있음(화면 위치는 개발자에게 확인) | |
| 구글 로그인 | 시험용 계정으로 직접 로그인해 보고 결과를 적기. **지금은 되는지 모름** | |

### 에이전트에게 일 시키기
| 기능 | 설명 | 확인 |
|---|---|---|
| 작업 시키기 | 말로 시키면 에이전트가 사이트를 열고 클릭하고 정리함 | |
| 멈추기, 이어받기 | 일시정지, 정지, 사람이 직접 이어받기, 다시 이어서 하기 | |
| 활동 기록 | 에이전트가 무엇을 했는지 시간순으로 보기 | |
| 승인 창 | 보내기, 구매, 삭제처럼 되돌리기 어려운 동작은 사람에게 물음 | |
| 권한 단계 | 보기만 / 둘러보기 / 상호작용 / 전체 (설정에서 선택) | |
| 한 번에 하나 / 여러 개 동시에 | 설정의 실행 방식. 여러 개 동시는 메모리 한도 안에서만 | |
| Halo 채팅 | 작업 진행 중 에이전트와 대화(⌘Shift+.) | |
| CAPTCHA | 풀지 않고 다른 출처로 돌아가거나 사람에게 넘김 | |
| PDF 읽기 | 페이지에 PDF가 열려 있으면 글을 읽어 줌 | |

### 에이전트, 팀, 루틴
| 기능 | 설명 | 확인 |
|---|---|---|
| 에이전트 만들기 | 이름, 직함, 역할 지침, 모델, 아바타, 능력(브라우저 / 화면 기반 컴퓨터 사용) | |

| 백그라운드 실행 | 로그인할 때 자동으로 시작하는 항목을 추가하는 기능(켜기 전에 확인 창이 뜸). 앱을 닫아도 루틴이 도는지는 개발자에게 확인 | |
| 메모리 | "모든 작업이 알아야 할 것"을 적어 두기 | |

### 모델과 고급 설정 (설정 화면, 대부분 기본 꺼짐)
| 기능 | 설명 | 확인 |
|---|---|---|
| 모델 선택 | Claude, Codex, Antigravity, Cursor, NVIDIA, OpenCode 중에서 고르기(각자의 CLI나 키가 필요) | |
| 빠른 모드 | 모델이 지원할 때만 더 빠른 응답 | |
| 막히면 위 모델로 | 실패하면 한 단계 위 모델로 다시 시도 | |
| 작업 길이로 모델 고르기 | 짧은 일은 빠른 모델, 긴 일은 강한 모델 | |
| Context Awareness | 읽은 페이지를 암호화해서 기억하고 나중 작업에 참고(결제·로그인 페이지 제외) | |
| 연구 모드 | "조사해서 출처 달아줘". **출처는 검증되지 않음**(Codex 리뷰 지적, 결정 대기 중) | |

### 안전장치 (이번에 추가한 것)
| 기능 | 설명 | 확인 |
|---|---|---|
| 결제 | **기본 꺼짐.** 켜면 채팅으로 "이 사이트에서 얼마 이하로 사줘"라고 한 것만 1회 허용 | |
| 카드, 주민번호, 비밀번호, 인증번호 | 에이전트가 보지도 입력하지도 못함. 입력창이 나오면 멈추고 사람에게 넘김 | |
| 전화번호, 이메일 | 요청에 적은 값과 똑같을 때만 입력 | |

### 아직 없거나 연결 안 된 것
- Slack으로 작업 보내기: 코드는 있으나 Slack과 연결되지 않음.
- 설정 화면의 결제 켜기/끄기 스위치: 아직 없음(코드에서만 바꿈).
- 탭을 끌어서 그룹에 넣기: 없음.
- Halo 앱 자체의 계정과 로그인(Google로 로그인 등): 없음. 계정 없이 내 컴퓨터에서만 동작.

## 3. 지금 어디까지 왔나 (솔직하게)
- 만든 지 3주차, 취미로 시작했습니다.
- **사용자 0명, 데모를 보여 준 적 없음.** 돈을 낸 사람도 없습니다.
- 다른 AI 브라우저(Aside, Atlas, Dia 등)를 써 본 사람 몇 명이 DM을 보냈지만, DM에 대한 답장을 받은 건 **보낸 2~3명 중 1명**뿐입니다. 그 한 문장: "헤일로는 어사이드와 달리 브라우저의 본질을 해치지 않으면 좋겠어요."
- 1월에 **제한적 공개 베타**를 하겠다고 이미 공개로 약속했습니다.

## 4. 두 사람의 역할
- **개발자(코드 담당)**: 코드, 결제와 개인정보 안전 규칙, 버그 수정.
- **당신(사용자와 피드백 담당)**: 사용자에게 말을 걸고, 쓴 사람의 말을 **원문 그대로** 모으고, 직접 써 보고 막힌 곳을 기록합니다.

둘 사이의 연결: 당신이 모은 원문을 개발자가 **일주일에 한 번 읽고**, 가장 많이 나온 것 하나를 다음 주 작업으로 고릅니다.

## 5. 첫 주 과제 (금요일까지)
DM을 보낸 핸들 3~4명에게 아래를 묻고, 답을 **요약하지 말고 그대로** 저장합니다.
1. 어느 브라우저에서 무슨 작업을 시켰나요?
2. 어떻게 실패했나요?
3. 그래서 잃은 게 있나요? (시간, 돈, 잘못된 주문)
4. (답장해 준 1명에게만) "브라우저의 본질"이 구체적으로 뭐예요? 어떤 게 깨지면 바로 닫으세요?

보내는 말은 광고처럼 보이면 안 됩니다. 예시:
> 안녕하세요, 지난번에 남겨 주신 글 봤어요. 저희가 만들고 있는 브라우저 때문에 여쭤봐요. 쓰시던 브라우저에서 어떤 작업이 어떻게 실패했는지 한 가지만 알려 주실 수 있을까요? 홍보 아니고 만들 때 참고하려고요.

답이 안 오면 그것도 결과입니다. "5명에게 보냈고 1명 답함"처럼 숫자를 그대로 적습니다.

## 6. 저장 방법
`docs/tester-reports/날짜-핸들.md` 한 파일에 한 사람씩 붙입니다. 깃을 못 다루면 구글 문서 하나에 모아서 개발자에게 넘겨도 됩니다. 적을 것: 사람(핸들), 날짜, 원문, 내가 한 질문.

## 7. 지켜야 할 것
- **카드, 주민번호, 비밀번호, 인증번호는 받지도 묻지도 않습니다.** 누가 보내 와도 저장하지 말고 지우라고 안내합니다.
- 테스트는 **시험용 계정**으로만 합니다. 개인 계정, 실제 카드는 쓰지 않습니다.
- 환불, 출시 날짜, "안전하다"는 말을 **약속하지 않습니다.** "확인해서 알려드릴게요"까지만 말합니다.
- 사고가 의심되면(시키지 않은 결제 같은 일) 바로 개발자에게 알리고, 사용자에게는 "결제가 필요한 작업은 잠시 하지 말아 주세요"라고만 말합니다. 자세한 순서는 `docs/incident-playbook.ko.md`.

## 8. 지금 하지 않아도 되는 것
가격, 로고, 랜딩 페이지, SNS 계정, 홍보 글. 사용자의 원문이 3개 이상 모이기 전에는 알릴 내용이 없습니다. 마케팅은 그 뒤에 시작합니다.

## 9. 직접 써 보는 것 (선택)
`docs/tester-guide.ko.md`의 작업 5개와 버그 리포트 양식을 쓰면 됩니다. 같은 작업을 다른 AI 브라우저에도 시켜서 결과를 옆에 적어 두면 비교 자료가 됩니다.

## 용어
- **에이전트**: 사람 대신 웹사이트에서 일을 하는 AI.
- **베타**: 정식 출시 전에 몇 명만 먼저 써 보는 시험 단계.
- **원문**: 상대가 쓴 말 그대로. 요약하거나 고치지 않은 것.
- **CAPTCHA**: "로봇이 아닙니다" 확인 화면. Halo는 풀지 않고 사람에게 넘기거나 다른 출처로 돌아갑니다.
- **PR**: 코드 변경을 합치기 전에 사람이 검토하는 요청. 동업자는 몰라도 됩니다.

## 연락
막히면 혼자 오래 붙잡지 말고 바로 개발자에게 묻습니다. 모르는 게 있다는 건 문제가 아니고, 모르는 채로 사용자에게 약속하는 게 문제입니다.
