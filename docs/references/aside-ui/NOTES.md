# Aside 브라우저 UI 참고 노트 (2026-10-07)

Aside 1.0.928.1(macOS)을 직접 실행해 보고 정리한 **참고용** 메모입니다. 화면을 그대로 복제하는 것이 아니라 구조와 상호작용 아이디어를 Halo에 어떻게 가져올지 판단하기 위한 자료입니다.

스크린샷(`01-…`, `02-…`)에는 사용자 계정 이름과 프로필이 보입니다. 저장소에 커밋하거나 공유하기 전에 가려 주세요.

## 전체 레이아웃 (3열)

| 영역 | 내용 |
| --- | --- |
| 왼쪽 사이드바 | Bookmarks(탭을 끌어다 놓는 점선 영역), Chats(New Chat + 최근 대화 + "모두 표시"), Tabs(세로 탭, "+ 새 탭"), 하단에 프로필 메뉴와 검색 아이콘 |
| 가운데 | 일반 웹 콘텐츠. 상단 바: 뒤로/앞으로/새로고침, 주소(도메인 + 페이지 제목), 확장 프로그램, 숨겨진 툴바 버튼 `>>` |
| 오른쪽 에이전트 패널 | "Ask Aside"로 여닫는 패널. 상단에 "New chat ▾"와 새 대화/닫기. 하단 입력창 |

## 에이전트 패널 (Halo에서 가장 참고할 부분)

- 입력창 위에 **현재 탭을 컨텍스트 칩**(파비콘 + 제목 + 도메인)으로 붙임. `@`로 다른 컨텍스트를 추가.
- 입력창 아래 한 줄 컨트롤: 실행 모드 아이콘(주황색), 도구/프로젝트 아이콘, **모델 + 추론 수준**(예: `Sonnet 5.5  Low`).
- 추론 수준 메뉴: Low / Medium / High / Extra High / Max / **Ultrabrowse**(무지개색 강조, 끝까지 자율 실행).
- 전송은 ↑ 원형 버튼. 입력이 있으면 마이크가 작아지고 ↑가 나타남.
- 응답은 "Worked for 15s ▸"처럼 **작업 시간을 접은 줄**로 요약하고, 결과 불릿과 페이지 스크린샷 썸네일을 이어서 보여 줌. 하단에 시각과 아이콘(복사 등).
- 대화는 사이드바 Chats에 제목이 자동 생성되어 쌓임.

## 주소창/홈

- 새 탭은 Search/Ask 두 모드 토글(`Tab`으로 전환). Search는 구글 검색, Ask는 에이전트.
- 홈 화면은 "Suggested tasks" 카드 3장: Set up Aside's memory / Automate my routines / Customize Aside. 카드마다 "Use this prompt" 또는 "Open Settings".
- 우상단 "Invite friends" 배지(닫을 수 있음)와 프로필 아바타.

## Settings 구조 (사이드 내비게이션)

- **Personal**: General, Appearance, Account, Plan & Usage, Security & Privacy(New)
- **Agent**: Agents, Projects, Models, Plugins & MCPs, Memory, Context Awareness(New)
- **Features**: Passwords, Routines, Channels, Developers, Mini popup, Lasso
- **Archived**: Archived chats
- 하단 링크: Send feedback, Extensions, Docs, Community
- 상단에 설정 검색창. 설정도 일반 탭("Settings › General")으로 열림.
- General 항목 예: 기본 검색엔진, 새 탭 모드(Search/Ask), 자동 PiP, 스크린샷(우클릭 메뉴), 선호 언어, 맞춤법, 다른 브라우저에서 가져오기.
- 설정 행 스타일: 제목 + 보조 설명 + 우측 컨트롤(토글/드롭다운/버튼)이 카드 안에 한 줄씩.

## 온보딩 (4단계)

1. 다른 브라우저에서 가져오기(Safari, ChatGPT Atlas), Skip 가능.
2. "No more integrations": 로그인한 사이트를 사람처럼 쓴다는 설명. 앱 아이콘이 떠다니는 애니메이션과 예시 프롬프트 말풍선.
3. "Let Aside sign in so the work doesn't get stuck": Vault로 자격 증명 가져오기 / 비밀번호 관리자 연결, Skip 가능. 오른쪽에 예시 대화 미리보기. 하단에 "설정 > Password에서 나중에 가능" 안내.
4. "Choose your AI subscription": Aside 기본 플랜(Recommended) / ChatGPT / Claude 구독 재사용, "Show more options".
- 공통: 하단 중앙 4개 점 진행 표시, 좌 Back, 우 Next/Continue(⏎ 단축키 표시).

## Halo에 가져올 만한 UI 아이디어

1. 에이전트 패널의 **현재 탭 컨텍스트 칩**과 `@` 컨텍스트 추가.
2. 모델과 추론 수준을 입력창 바로 아래 한 줄에 두기.
3. 응답을 "Worked for Ns"로 접어 두고 결과만 먼저 보여 주기.
4. Search/Ask 두 모드를 한 입력창에서 `Tab`으로 전환.
5. 설정을 일반 탭으로 열고 내비게이션 그룹(Personal/Agent/Features)으로 정리.
6. 온보딩 모든 단계에 Skip을 두고, 늦게 설정할 위치를 안내하기.

## 관찰된 한계 (참고)

- 웹뷰 UI가 접근성(AX) 클릭을 무시해서 자동화로는 버튼을 누를 수 없었음. 실제 마우스 입력이 필요.
- 작업이 끝나도 renderer 수와 메모리가 줄지 않음(2.2 GB 안팎, 14~17개 프로세스).

## 디자인 요소 (다크 테마, 창 1920×1560 캡처에서 샘플링)

색(대략값, 픽셀 샘플):
- 사이드바/입력 카드/사용자 말풍선/선택된 탭 행: `#343434`
- 에이전트 패널 배경: `#232323` (사이드바보다 한 단계 어두움)
- 웹 콘텐츠 영역 배경은 페이지 자체(구글 다크 `#222429`)
- 강조: 주황색(실행 모드 아이콘), 전송 버튼은 흰색 원 + 검정 ↑, 선택 영역은 파란 하이라이트
- 한 면에 한 톤씩 쓰고 경계선은 거의 없음. 카드와 패널의 구분은 명도 차이로 처리.

형태/간격:
- 입력 카드와 말풍선: 큰 반경(약 16~20px), 안쪽 여백 약 12px, 컨텍스트 칩은 카드 안쪽 상단에 작은 반경(약 8px)으로 중첩.
- 사이드바 행: 높이 약 32px, 반경 약 8px, 선택 행만 면 색 채움, 아이콘 16px + 텍스트 13px 안팎.
- 섹션 헤더(Bookmarks/Chats/Tabs)는 작은 회색 라벨, 섹션 간격 넉넉함.
- 북마크 영역은 점선 테두리의 드롭 영역.

타이포:
- 시스템 산세리프(San Francisco 계열), 본문 13~14px, 라벨 11~12px, 대화 본문은 회색 톤 낮춤(흰색 아님).
- 시각, 도구 요약("Worked for 5s")은 더 옅은 회색과 작은 크기.

컴포넌트/상태:
- 응답 구조: 사용자 말풍선(우측 정렬) → "Worked for Ns ›"(접힘) → 결과 문단 → 불릿(굵은 라벨 + 값) → 시각 + 아이콘.
- 진행 중에는 패널 제목이 현재 작업("Fetching example.com…")으로 바뀌고 입력창 우측에 스피너.
- 새 대화는 Chats 목록 맨 위에 작업 요약 제목으로 즉시 생성.
- 에이전트가 연 탭은 Tabs 목록에 파비콘+제목으로 추가되고 가운데 영역이 그 탭으로 전환.

Halo에 옮길 때의 메모: 색과 반경은 Halo의 기존 유리(vibrancy) 스타일을 유지하고, 구조(칩, 모델/추론 한 줄, 접힌 작업 요약, 진행 중 제목 변경)만 참고하는 것이 안전합니다. 위 수치는 샘플링 근사값이라 정확한 토큰이 아닙니다.
