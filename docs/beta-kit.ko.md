# 1월 배타 준비물

배타의 목적은 하나입니다. **"HALO가 없어지면 곤란한 사람이 있는가"를 확인하는 것.** 칭찬은 세지 않습니다. 매주 다시 쓰는 사람만 셉니다.

## 1. 사람 찾기 (12월까지)
첫 사용자는 Aside, Comet, Atlas 같은 AI 브라우저를 써 본 사람이 낫습니다. 설명이 필요 없고, 지금 쓰는 방법이 있어서 비교가 됩니다.
- 목표: 이름이 있는 사람 5명. "학생들" 같은 묶음은 사람이 아닙니다.
- 아래 표에 이름만 먼저 적습니다. 못 채우면 코드보다 이것이 먼저입니다.

| # | 이름(또는 아이디) | 어디서 만났나 | 지금 쓰는 도구 | 인터뷰 날짜 | 배타 참여 |
|---|------------------|--------------|---------------|------------|-----------|

| 2 | | | | | |

## 2. 인터뷰 질문 (HALO 이야기는 하지 마세요. 듣기만)
1. 최근에 AI 브라우저(또는 AI 에이전트)로 뭘 시켜 봤어요? 가장 최근 일을 말해 주세요.
2. 그걸 계속 쓰고 있어요? 안 쓰게 됐다면 왜요?
3. 결제나 로그인이 필요한 일을 AI에게 맡겨 본 적 있어요? 맡기기 전에 뭐가 걱정됐어요?
4. 그 일이 없으면 하루(또는 한 주)에 몇 분이 더 들어요?
5. 지금 그 일을 어떻게 해결하고 있어요? (직접 클릭, 다른 도구, 사람 시키기)
6. 이 문제로 돈을 쓴 적 있어요? 얼마?

받아 적을 때는 그 사람이 한 말을 그대로 옮깁니다. 요약하지 마세요.

## 3. 배타를 열기 전 직접 확인 (실제 앱, 개발자 컴퓨터)
아래는 테스트 코드로는 확인할 수 없어서 사람이 앱을 켜서 봐야 합니다. 하나라도 안 되면 배타 시작 전에 고칩니다.
- [ ] `npm start` (Chromium 방식)에서 마이크 버튼 → 말하기 → 글자가 채팅창에 들어간다 (자동 전송은 안 된다)
- [ ] 구글 로그인이 된다
- [ ] 맥 패키지를 실제 맥에서 열었을 때 마이크 허용 창이 뜬다 (`tools/package-mac.sh --extend-info`)
- [ ] 결제는 꺼진 상태로 시작하고, `node tools/halo-admin.js status`에 payments off로 보인다
- [ ] 가짜 쇼핑몰(`fixtures/fake-shop-server.js`)에서 "$20 이하로 구매해줘"가 한 번만 결제되고 두 번째는 막힌다
- [ ] 배타 만료일이 설정에 맞게 보인다
- [ ] 비상 시 `node tools/halo-admin.js payments off`로 결제가 즉시 꺼진다 (`docs/incident-playbook.ko.md`)

## 5. 1월 말에 답할 질문 (YC든 아니든)
- 배타 참여자 중 2주 연속 쓴 사람이 몇 명인가?
- "없어지면 곤란하다"고 말한 사람이 있는가? 그 말을 그대로 옮기면?
- 사람들이 HALO를 설명하는 말이 내 설명과 같은가?
이 세 질문의 답이 지원서의 중심 내용이 됩니다.
