# 고부하 벤치마크 — 2026-09-13

Rust 구현의 수치 검증과 합성 방어 성능을 구분해 평가했다. 새 `hard_bench` 실행기는 설정·seed·결과·소요 시간·실패 내역을 JSON에 보관하며, 불변식 위반 시 종료 코드 1을 반환한다.

## 실행 규모와 결과

| 실험 | 설정 수 | 설정당 규모 | 합계 실행 시간 |
|---|---:|---|---:|
| E001 | 20 | 20만 표본, 오염률 0–100%, seed 5개 | 0.274초 |
| E001B | 45 | 25만 표본, 오류율 최대 95%, 상관계수 최대 1 | 0.866초 |
| E002 | 30 | 정상 10만 + 공격 10만, 숨겨진 공격 비율 0–100%, FPR 0.01%/10% | 0.530초 |
| E003 | 48 | 5만 자원 × 256/257 단계, 변동률 0–100% | 8.463초 |
| E004 | 5 | 기본 크기 n=10만, 내부 생성 총 100만 표본 | 0.093초 |
| E005 | 20 | 모집단 1만 × 100라운드, static/moving 각 seed 10개 | 1.314초 |

168개 워크로드의 불변식 검증에 실패가 없었다. 전체 실행은 로컬 release 빌드에서 11.547초였다. 시간에는 검증 비용이 포함되며, 반복 성능 측정이나 Python 대비 속도 비교는 아니다. E003의 총 6억 1,560만 자원 단계는 독립 표본 수가 아니다. E005의 총 2천만 후보 평가는 적응 과정의 반복 관측이다.

별도 E004 검증 512건은 동점 점수, 임계값 포함 경계, 희소 집단, 극단 가중치(1e308), 집단 분할 불변성을 독립 집계와 비교해 통과했다. 여섯 모듈의 잘못된 표본 크기 입력 36건도 모두 거부했다. 기존 파라미터 그리드 140개는 n=1만으로 정상 실행했다.

자동 테스트는 통계 워크스페이스 39개와 OS 실행기 12개가 통과했다. 새 실행기까지 포함한 통계 워크스페이스 Clippy 검사도 경고를 오류로 처리해 통과했다.

## 어려운 조건에서의 관측

다음은 지정한 seed들의 평균이며 실제 공격 성공률을 추정하는 결과가 아니다.

- E001B: 오류율 95%, 상관계수 1에서 단일 소스와 중복 fail-closed의 실패율이 동일한 19.82%였다. correlation-aware도 14.55%가 남았다.
- E002: 전부 숨겨진 공격일 때 FPR 0.01%에서 algorithm-diverse 탐지율은 0.013%, evidence-diverse는 35.13%였다. FPR 10%로 완화하면 각각 11.55%, 97.69%였다. 낮은 오탐 예산에서 탐지력이 크게 줄어든다.
- E003: 지연 257, 변동률 0.1, 갱신 창 32에서 cached 실패율은 48.90%, fixed/progressive는 24.99%였다. 사용 시점 재검증과 adaptive는 이 합성 모델에서 0%였다. 후자의 결과를 실제 시스템 무결함 보장으로 해석하면 안 된다.
- E005: 100라운드 후 실패율은 static 33.40%, moving 26.31%였다. 초기 대비 증가 폭은 각각 20.32/14.16%p였다. 이동 방어도 적응에 따른 실패 증가를 제거하지 못했다. 평균 정상 오차단율은 각각 10.14%/10.12%였다.

## 실제 임시 샌드박스

기존 정상 작업 3종과 공격 canary 9종을 세 모드에서 각각 20회 반복했다. 총 720회이며, 서로 다른 공격 경로 720종을 뜻하지 않는다.

|---|---:|---:|---:|---:|
| 비격리 대조군 | 60/60 | 0/180 | 180/180 | 0 |
| 환경·FD 상속 | 60/60 | 140/180 | 40/180 | 0 |

상속 모드의 환경변수·열린 FD 노출은 의도한 대조 결과다. 임시 fixture 삭제도 확인했다. 기본 9종 검사 범위이며 OS 확장 탈출 검사 전체나 메타데이터 비공개를 보장하지 않는다.

## 재현

저장소 루트에서 실행한다. 전역 Cargo가 없으면 README의 프로젝트 로컬 툴체인 접두사를 사용한다.

```sh
cargo build --release --locked --manifest-path rust/Cargo.toml
rust/target/release/hard_bench --output rust/results/hard-bench-2026-09-13.json
rust/target/release/parameter_stress --experiment all --n 10000 --output rust/results/parameter-stress-hard-2026-09-13.json
cargo build --locked --manifest-path artifacts/sandbox_benchmark/rust_runner/Cargo.toml
artifacts/sandbox_benchmark/rust_runner/target/debug/halo-sandbox-runner --repeats 20 --output rust/results/sandbox-hard-2026-09-13.json
```

원시 JSON은 로컬 `rust/results/`에 저장되며 Git에서 제외된다. 설정과 seed는 각 보고서에 포함된다.
