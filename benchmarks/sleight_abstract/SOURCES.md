# Sources

- SLEIGHT-Bench: Finding Blind Spots in AI Monitors (Najt, Toft, Tracy, Roger, Benton; 2026). Public benchmark defines 40 attacks across 11 monitor blind-spot categories and calibrates paired benign transcripts at 1% false-positive rate.
- AgentDojo: A Dynamic Environment to Evaluate Prompt Injection Attacks and Defenses for LLM Agents (Debenedetti et al.; 2024). Extensible tool-agent benchmark with 97 realistic tasks and 629 security test cases.

HALO does not copy the SLEIGHT encrypted transcripts or prompt-injection payloads into this benchmark. Only the public category taxonomy is represented as non-operational structured metadata.
